# Biztonsági hibák bejelentése

Ha biztonsági hibát találsz (pl. a belépők kezelésében, a helyi kezelőfelületben vagy a telepítőben),
**ne nyiss nyilvános issue-t**. Használd a GitHub privát bejelentését: a repó **Security** fülén a
**Report a vulnerability** gomb. Mielőtt bármit közzéteszel, adj időt a javításra.

Ne tegyél semmilyen jelszót, TOTP-kulcsot vagy valós ügyféladatot se issue-ba, se pull requestbe.
